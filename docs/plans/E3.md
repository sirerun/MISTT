fidelity: executable
Acceptance: owner-controlled stable distribution contains signed/notarized app/relay, signed Sparkle feed and an installable cask, with release and update safety checks.

Coding is authorized before working-MVP acceptance; actual signing/release remains gated. Establish Developer ID/notary access using the existing account, signing-key ownership/recovery and CI secrets; human-only credential issuance/import remains explicit if needed. Implement Sparkle checks and automatic stable updates, an external opt-out, quiet idle install deferral and muted restart with both sources closed. Preserve microphone and system-audio permission attribution through the same native bundle identity. Validate first-run update consent and macOS dialogs against the minimal main UI. Keep version/build identifiers monotonic, minimum macOS 14.2+ and Apple Silicon architecture correct, and archive/feed signatures verified. Test wrong signatures, wrong bundle/architecture, incompatible OS, downgrade, interrupted download and updater restart failures; the working version must survive.

Create/reuse an owner-controlled tap, tentatively `sirerun/homebrew-tap`, cask token `mistt`, `app "MISTT.app"`, SHA256 and `auto_updates true`. Release artifacts and HTTPS appcast come from reviewed landed revisions using GitHub tooling, not workstation-only manual uploads. Pin dependencies; validate CGO/dynamic-library bundling and license notices. Cask audit/install/uninstall and notarization/Gatekeeper checks are required. Feed publication follows verified artifact publication. Cross-repository publication is staged rather than atomic: update the cask with compare-and-swap and promote the stable feed last; record recovery steps on failure. Expanded tasks must include preflight, implementation, changed-behavior verification, independent exact-head review, merge, landed verification, and explicit release/publish verification.
