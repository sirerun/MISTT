# Xcode UI previews

Open `MISTTPreview.xcodeproj` in Xcode, select `PreviewApp.swift`, and enable **Editor → Canvas**. Press **Resume** in the canvas. Named previews show Muted, On with three clients, and Unavailable. Running this preview host also lets you click the microphone to toggle its fixture.

This target compiles the production `MicrophoneWindow.swift` and presentation model with a preview-only controller. It has no capture, relay, updater, Sparkle, or network dependency. It previews UI, not end-to-end audio behavior.

Derived data is configured on the external BuildOffload volume. The isolated target built successfully using Xcode 27.0 on 2026-10-04; Canvas rendering is not confirmed. Full native build, capture validation, installation, and runtime acceptance remain deferred.

The preview build fixed the production contrast environment key, unsupported live-region modifier, and missing client-count return. Status decoding moved unchanged to `RelayStatusDecoding.swift` so this target includes only the presentation model.

## Floating overlay

The production and fixture windows now use a hidden title bar, clear nonopaque background, no shadow, floating window level, background dragging, and all-spaces/full-screen-auxiliary collection behavior. The microphone grille is transparent. Floating means above ordinary application windows; system alerts and higher-level overlays may still appear above it.

The isolated host built successfully and was launched locally on 2026-10-04. Window screenshots show the background fill and chrome removed, and the fixture control exposes On with three clients after toggling. Native audio/runtime acceptance remains deferred. macOS 15+ also explicitly clears the SwiftUI window container; older supported systems need a visual check of the fallback.

## Dragging and default position

The overlay starts 24 points from the bottom-right corner of the current screen's visible work area, above the Dock. It uses WindowDragGesture with activation events on macOS 15+, and an AppKit pan recognizer on macOS 14. The preview bundle has a separate identifier to distinguish this host from older previews. Window attachment does not reset the same window after a user moves it.

The isolated target builds successfully. Live drag automation returned `noWindowsAvailable`, so drag movement and initial screen placement remain to be confirmed interactively. Open this worktree's project and run its fixture host to check the current implementation; previous running preview builds do not update automatically.

The production and preview app bundle icons now use the yellow enabled microphone. `Resources/AppIcon.icns` includes native macOS icon sizes generated by `scripts/generate-app-icon.swift`; regenerate its PNG iconset and convert with `iconutil` after changing the mark.
